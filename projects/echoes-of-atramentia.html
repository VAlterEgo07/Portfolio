About the project

Echoes of Atramentia is a unique drawing-based magic system game. Is still a WIP so expect big changes!

Game Features

Unique Drawing-Based Magic System

Players can draw their own spells and magical symbols to cast powerful abilities. The game recognizes the drawn shapes and translates them into in-game effects, allowing for a highly customizable and creative gameplay experience.

For now, the program detects the basic sigils but making spells from them is still in development.

PD: This is a simple demonstration of the magic system in action. All the prints in the console are a mixture of the drawing one and the combat system

Interactive Planting System

A core mechanical feature allowing players to cultivate and manage resources within the game world.

More...

There are many more features in development, including a rich storyline, character customization, and multiplayer interactions. Stay tuned for updates!
